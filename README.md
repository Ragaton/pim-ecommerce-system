# Product Information Management System

A C#/.NET Product Information Management (PIM) system developed as part of a
Software Engineering semester project at the University of Southern Denmark (SDU).

## Project Overview

This project was developed as part of a larger e-commerce system consisting of
multiple components. The PIM system is responsible for managing product
information, categories, product variants, attributes, pricing, and related
operations.

## My Contribution

My primary contribution to the project was the Product Information Management
(PIM) system.

I worked on:

- Product creation, editing, and deletion
- Product variants and pricing
- Product categories and attributes
- Product information persistence using PostgreSQL
- Change logging
- JSON export functionality
- The PIM user interface
- Integration tests for product-related functionality

## Technologies

- C#
- .NET 9
- Avalonia UI
- PostgreSQL
- Npgsql
- NUnit

## Testing

The project includes integration tests covering product creation,
database persistence, categories, variants, attributes, and related
acceptance criteria.

## Project Structure

- `PIM/` — Main Product Information Management application
- `PIM.Tests/` — Integration tests
- `Common/` — Shared interfaces, DTOs, and models
